# LLM Prompt 中的特殊 XML Tag（表格）

> 范围：会进入 **发给模型的消息**（system / user / tool_result）里的结构化标签。  
> 源码：`claude-code-rev`  
> **不是** UI 渲染分流用的内部标记（那些见旧稿时可忽略）。

系统 prompt 原话（`constants/prompts.ts`）：

> Tool results and user messages may include `<system-reminder>` or other tags. Tags contain information from the system.

---

## 总表

| Tag | 进 LLM 的位置 | 作用（模型应如何理解） | 对应功能 / 产生处 | 简单例子 |
|-----|---------------|------------------------|-------------------|----------|
| **`system-reminder`** | user 消息、tool_result 文本 | **系统自动注入的提醒/上下文**，与所在消息主题无必然关系；勿当作用户原话；一般不要复述给用户 | 通用包装：`wrapInSystemReminder`（`messages.ts`）。覆盖 plan/auto、IDE、todo、hook、compact、FileRead malware 护栏等 | `<system-reminder>`<br>`The user opened the file src/app.ts in the IDE.`<br>`</system-reminder>` |
| **`env`** | **system prompt** | 运行环境快照：cwd、是否 git、平台、shell、OS | `computeEnvInfo`（`constants/prompts.ts`） | `<env>`<br>`Working directory: /Users/me/proj`<br>`Is directory a git repo: Yes`<br>`Platform: darwin`<br>`</env>` |
| **`user-prompt-submit-hook`** | 文档约定会出现在 user 侧 | **当作来自用户**；若 hook 拦截则调整行为 | 系统 prompt hooks 说明；实际多经 `system-reminder` 注入 | 约定形态：`<user-prompt-submit-hook>lint passed</user-prompt-submit-hook>`<br>常见实装：`<system-reminder>UserPromptSubmit hook success: lint passed</system-reminder>` |
| **`new-diagnostics`** | user（外包 `system-reminder`） | 新出现的 IDE/LSP 诊断列表 | attachment `diagnostics` | `<new-diagnostics>`<br>`The following new diagnostic issues were detected:`<br><br>`src/a.ts:10: error TS2322: ...`<br>`</new-diagnostics>` |
| **`mcp-resource`** | user（外包 `system-reminder`） | MCP resource 无正文/不可展示时的占位（`server` / `uri`） | attachment `mcp_resource` | `<mcp-resource server="docs" uri="docs://readme">(No content)</mcp-resource>` |
| **`available-deferred-tools`** | user | 可经 ToolSearch 拉取的延迟工具名列表 | `services/api/claude.ts` | `<available-deferred-tools>`<br>`mcp__slack__post_message`<br>`mcp__github__create_issue`<br>`</available-deferred-tools>` |
| **`functions` / `function`** | tool_result（ToolSearch） | 工具完整 JSONSchema；出现后可调用 | `ToolSearchTool` | `<functions>`<br>`<function>{"name":"mcp__slack__post_message","parameters":{...}}</function>`<br>`</functions>` |
| **`persisted-output`** | tool_result | 超长输出已落盘；需再 Read 路径 | `toolResultStorage.ts` | `<persisted-output>`<br>`Output too large. Full output: /tmp/claude/.../tool-out.txt`<br>`</persisted-output>` |
| **`tool_use_error`** | tool_result | 工具调用失败 | `toolExecution.ts` | `<tool_use_error>Error: No such tool available: FooBar</tool_use_error>` |
| **`error`** | tool_result（Bash/PS） | 命令中止等错误片段 | `BashTool` / `PowerShellTool` | `<error>Command was aborted before completion</error>` |
| **`sandbox_violations`** | tool_result（常嵌 stderr） | 沙箱拦截详情 | Bash 沙箱路径 | `<sandbox_violations>`<br>`network: connect to 1.2.3.4:443 denied`<br>`</sandbox_violations>` |
| **`task-notification`** | user（合成） | 后台任务完成/失败/停止通知 | `task/framework.ts` 等 | 见下一行起的子字段拼成的完整块（示例在下） |
| **`task-id`** | 嵌在 `task-notification` | 任务/worker ID | 同上 | `<task-id>a1b2c3d4e5f67890</task-id>` |
| **`tool-use-id`** | 嵌在 `task-notification` | 关联的 tool_use（可选） | 同上 | `<tool-use-id>toolu_01ABC...</tool-use-id>` |
| **`task-type`** | 嵌在 `task-notification` | 任务类型 | 同上 | `<task-type>local_agent</task-type>` |
| **`output-file`** | 嵌在 `task-notification` | 输出文件路径 | 同上 | `<output-file>/tmp/claude/tasks/a1b2/out.txt</output-file>` |
| **`status`** | 嵌在通知等 | `completed` / `failed` / `killed`… | 同上 | `<status>completed</status>` |
| **`summary`** | 嵌在 `task-notification` | 人类可读摘要 | 同上 | `<summary>Task "fix login bug" completed successfully</summary>` |
| **`reason`** | 嵌在通知类消息 | 原因说明 | task / MCP update | `<reason>resource updated by server</reason>` |
| **`worktree` / `worktreePath` / `worktreeBranch`** | 嵌在 `task-notification` | 子 agent 的 worktree | `LocalAgentTask` | `<worktree><worktreePath>/repo/.claude/worktrees/fix-login</worktreePath><worktreeBranch>worktree-fix-login</worktreeBranch></worktree>` |
| **`bash-input`** | user | `!` bash 模式敲的命令 | `processBashCommand.tsx` | `<bash-input>ls -la src/</bash-input>` |
| **`bash-stdout` / `bash-stderr`** | user | 上述 bash 的输出 | 同上 | `<bash-stdout>app.ts\nindex.ts</bash-stdout><bash-stderr></bash-stderr>` |
| **`command-name` / `command-message` / `command-args`** | user | 斜杠命令 / Skill 元数据 | `processSlashCommand.tsx` | `<command-name>/commit</command-name>`<br>`<command-message>commit</command-message>`<br>`<command-args>-m "fix typo"</command-args>` |
| **`skill-format`** | user | `true` = Skill 已加载格式 | 同上 | `<skill-format>true</skill-format>` |
| **`local-command-stdout` / `local-command-stderr`** | user | 本地斜杠命令输出 | 同上 | `<local-command-stdout>Model set to sonnet</local-command-stdout>` |
| **`local-command-caveat`** | user（meta） | 后续是本地命令产物，勿当作用户提问 | `messages.ts` | `<local-command-caveat>Caveat: The messages below were generated by the user while running local commands. DO NOT respond...</local-command-caveat>` |
| **`scheduled-task-result`** | user | 定时任务跑完的斜杠命令结果 | `processSlashCommand.tsx` | `<scheduled-task-result command="/remind">`<br>`Done: reminded user`<br>`</scheduled-task-result>` |
| **`tick`** | user（proactive） | 主动模式周期 check-in | proactive / `main.tsx` | `<tick>check-in</tick>` |
| **`teammate-message`** | user | Swarm 队友消息 | `teammateMailbox` | `<teammate-message teammate_id="alice" summary="PR ready">`<br>`I finished the auth refactor.`<br>`</teammate-message>` |
| **`channel`** | user | 外部 MCP channel 推送 | `channelNotification.ts` | `<channel source="slack">`<br>`@claude please review PR #42`<br>`</channel>` |
| **`cross-session-message`** | user | 另一会话发来的消息 | SendMessage / UDS | `<cross-session-message from="sess_abc">`<br>`Can you take the frontend half?`<br>`</cross-session-message>` |
| **`fork-boilerplate`** | user（fork 首条） | Fork 子会话规则样板 | `forkSubagent.ts` | `<fork-boilerplate>`<br>`(rules…)`<br>`Your directive: Fix the flaky test in auth.spec.ts`<br>`</fork-boilerplate>` |
| **`ultraplan`** | 远程规划输出 | ultraplan 正文边界 | `RemoteAgentTask` | `<ultraplan>`<br>`## Plan\n1. Add tests\n2. Fix race`<br>`</ultraplan>` |
| **`remote-review` / `remote-review-progress`** | 远程 review 输出 | 评审结果 / 进度心跳 | 同上 | `<remote-review>## Findings\n- N+1 query in listUsers</remote-review>`<br>`<remote-review-progress>{"phase":"analyzing","pct":40}</remote-review-progress>` |
| **`team-memory-content`** | user / 上下文 | 团队共享 memory 内容 | `claudemd.ts` | `<team-memory-content source="shared">`<br>`# API conventions\nAlways use zod...`<br>`</team-memory-content>` |
| **`cell` / `cell_type` / `language`** | tool_result（notebook） | Notebook 单元格 | `notebook.ts` | `<cell id="c1"><cell_type>code</cell_type><language>python</language>print(1)</cell id="c1">` |
| **`claude-code-hint`** | tool stdout/stderr | 厂商 hint（插件推荐） | `claudeCodeHints.ts` | `<claude-code-hint name="gh" />` |
| **`mcp-resource-update` / `mcp-polling-update`** | user | MCP 资源或轮询有更新 | MCP 订阅通知 | `<mcp-resource-update server="fs" uri="file:///a.ts"><reason>changed</reason></mcp-resource-update>` |
| **`github-webhook-activity`** | user | GitHub webhook 活动 | Kairos webhook | `<github-webhook-activity>`<br>`check_run completed: CI passed on main`<br>`</github-webhook-activity>` |
| **`user-memory-input`** | user | 用户提交的 memory 正文 | memory 输入 | `<user-memory-input>`<br>`Prefer pnpm over npm in this repo.`<br>`</user-memory-input>` |
| **`retrieval_status` / `task_id` / `task_type` / `exit_code` / `output`** | tool_result（TaskOutput） | 后台任务输出结构化字段 | `TaskOutputTool` | `<retrieval_status>success</retrieval_status><task_id>…</task_id><status>completed</status><exit_code>0</exit_code><output>\nok\n</output>` |

### `task-notification` 完整拼装示例

```xml
<task-notification>
<task-id>a1b2c3d4e5f67890</task-id>
<tool-use-id>toolu_01ABC</tool-use-id>
<task-type>local_agent</task-type>
<output-file>/tmp/claude/tasks/a1b2/out.txt</output-file>
<status>completed</status>
<summary>Task "fix login bug" completed successfully</summary>
</task-notification>
```

## 按功能归类（便于对照代码）

### 1. 系统 prompt 自带

| Tag | 功能 |
|-----|------|
| `env` | 环境信息块 |
| （文案提及）`system-reminder`、`user-prompt-submit-hook` | 教模型如何对待后续注入 |

### 2. Attachment → 注入（几乎都包在 `system-reminder` 里）

入口：`normalizeAttachmentForAPI`（`messages.ts`）+ `attachments.ts` 收集。

| 功能 | 典型内容 | 是否另有专用 tag |
|------|----------|------------------|
| Plan / Auto 模式 | 模式规则全文 | 通常只有外层 `system-reminder` |
| IDE 打开文件 / 选区 | 文件名、选中行 | 现多为纯文本 + `system-reminder` |
| Todo / Task / Memory 提醒 | 提醒文案 | `system-reminder` |
| LSP 诊断 | 诊断摘要 | **`new-diagnostics`** + `system-reminder` |
| MCP resource | 资源正文或占位 | **`mcp-resource`**（空内容时） |
| Hook 成功/拦截/附加上下文 | hook 名 + 输出 | `system-reminder`（文案里带 hook 名） |
| Compact / 日期 / Agent 列表增量等 | 提醒或列表 | `system-reminder` |
| Critical reminder | `attachment.content` | `system-reminder` |

### 3. 工具结果里的标签

| 功能 | Tag |
|------|------|
| FileRead 安全/空文件 | `system-reminder` |
| 大输出落盘 | `persisted-output` |
| 工具失败 | `tool_use_error`、`error` |
| ToolSearch | `functions` / `function`；列表侧 `available-deferred-tools` |
| Notebook | `cell`… |
| 沙箱 | `sandbox_violations` |

### 4. 「看起来像 user、其实是协议」的消息

| 功能 | Tag |
|------|------|
| `!` bash | `bash-input` / `bash-stdout` / `bash-stderr` |
| `/` 命令与 Skill | `command-*`、`skill-format`、`local-command-*` |
| 后台任务完成 | `task-notification` + 子字段 |
| Swarm / 多会话 | `teammate-message`、`channel`、`cross-session-message` |
| Proactive | `tick` |

## 关键辅助函数

| 符号 | 文件 | 作用 |
|------|------|------|
| `wrapInSystemReminder` | `src/utils/messages.ts` | 单段文本包 `<system-reminder>` |
| `wrapMessagesInSystemReminder` | 同上 | 对整条 user message 包一层 |
| `normalizeAttachmentForAPI` | 同上 | attachment → 模型可见 user 消息 |

## 读表时注意

1. **`system-reminder` 是总包装器**：很多功能没有自己的 tag，只是把说明文字塞进它。  
2. **专用 tag**（`new-diagnostics`、`task-notification`、`available-deferred-tools`…）才是「名字本身携带语义」的协议。  
3. 系统 prompt 写的 `<user-prompt-submit-hook>` 是**约定名**；当前实现更常见的是 `system-reminder` + `"UserPromptSubmit hook …"` 纯文本。  
4. UI 会隐藏很多这类消息（`isMeta` / `UserTextMessage` 分流），但 **API 请求里模型仍能看到**。
