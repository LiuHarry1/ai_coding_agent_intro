网页与运行时关系图

同一门 JavaScript，可以跑在浏览器、Node.js、Electron 里。 差别主要在：有没有页面渲染（Blink / WebKit），以及包了哪些系统能力。

HTML CSS JS V8 Blink WebKit Chromium Node.js Electron

1. 打开一个网页时，谁处理什么？

HTML / CSS / JS 是你写的内容；Blink 负责把页面画出来；V8 负责执行 JS；Chrome 是完整产品。

HTML
结构：标题、按钮、段落……「页面里有什么」
CSS
样式：颜色、布局、字体……「长什么样」
JavaScript
行为：点击、请求数据、改页面……「怎么动」
▼ 交给浏览器组件处理
Blink
渲染引擎：读 HTML/CSS，计算布局并绘制页面
V8
JS 引擎：执行 JavaScript（不负责画页面）
▼ 组装成产品
Chrome
完整浏览器：Chromium 内核 + Google 服务、自动更新、同步等

2. Chromium ⊃ Blink + V8；Chrome ⊃ Chromium

Chromium 是开源浏览器项目；Blink / V8 是其中两块核心引擎；Chrome 基于 Chromium 再加闭源部分。

Chrome（产品）
Chromium（开源浏览器核心）
Blink
渲染引擎
处理 HTML + CSS → 页面画面
V8
JavaScript 引擎
处理 JS → 执行逻辑

还有网络栈、安全沙箱、DevTools……这里只突出和前端最相关的两块。

3. Chromium / Blink vs WebKit

都是「浏览器内核家族」，但路线不同。Safari 用 WebKit；Chrome / Edge / 新 Opera 等走 Chromium。

Chromium 路线

  • 渲染： Blink（从 WebKit 分叉出来）
  • JS： V8
  • 产品例子： Chrome、Edge、新 Opera、许多 Electron 应用

WebKit 路线

  • 渲染： WebKit
  • JS： JavaScriptCore（不是 V8）
  • 产品例子： Safari、部分 iOS 内嵌浏览器

记法：WebKit 和 Blink 都偏「画页面」； V8 和 JavaScriptCore 都偏「跑 JS」。不要把 V8 和 WebKit 当成同一层东西。

4. Chrome · Node.js · Electron：三套舞台

都可能用到 V8，但「有没有 Blink / 有没有 Node API」不同。

浏览器（Chrome）

看网页

有页面、有 DOM。用户访问网址时，在这里跑前端 JS。

V8 ✓ Blink ✓ Node API

Node.js

跑脚本 / 服务

没有网页 DOM。可读文件、起服务器。你项目的 tsx start.js 就在这条路上。

V8 ✓ Blink Node API ✓

Electron

桌面应用

内嵌 Chromium（会画 UI）+ Node（能碰系统）。你项目的 electron . 属于这里。

V8 ✓ Blink ✓ Node API ✓

5. 一条线串起来

从源码到不同产品，可以这样记：

HTML + CSS → Blink / WebKit → 页面画面
JavaScript → V8 （或 Safari 的 JSC）→ 执行逻辑
Blink + V8 + … → Chromium + Google 服务 → Chrome
V8 + 系统 API → Node.js ； Chromium + Node → Electron
