三档模型架构

Baize / src：对齐 Claude Code 的 large / medium / small 静态选型。每档可独立配置 provider、URL、key、model。

配置

{
  "models": {
    "large":  { "provider": "openai-compatible", "baseURL": "...", "apiKey": "...", "model": "claude-opus-4.6" },
    "medium": { "provider": "openai-compatible", "baseURL": "...", "apiKey": "...", "model": "claude-sonnet-4.6" },
    "small":  { "provider": "openai-compatible", "baseURL": "...", "apiKey": "...", "model": "claude-haiku-4.5" }
  }
}

回退：medium → large，small → medium → large。未配 models.large 时使用内置默认 profile。

任务绑定

任务档位说明
主循环 / GP / Plan / Compactlarge默认；compact 对齐 CC 用主模型
Explore 子 agentsmallmodelTier: 'small'
Session 标题small对齐 CC queryHaiku / sessionTitle
自定义 agentfrontmatter modelTier可选 large / medium / small

无智能路由：按调用点静态选型。关键代码：core/llm/model-registry.ts、services/sessionTitle.ts、tools/AgentTool/built-in/exploreAgent.ts。

API

  • GET /settings — 含 models（key 打码）
  • PATCH /settings/models — 改任意档
