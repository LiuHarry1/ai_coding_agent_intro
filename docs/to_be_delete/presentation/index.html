Core Agent Loop — Not a Chat, but a Loop

The essence of Coding Agent: the loop you implement drives multi-step LLM decisions until there are no tool calls or the limit is reached.

Chat vs Agent

Standard chatOne request, one response, then stop
Coding AgentA for (step…) loop inside query()
Stop conditiontoolCalls.length === 0

One runStep Iteration

📝sanitizeNormalize messages → API format
🤖streamTextCall the LLM (AI SDK)
🔧executeRun StreamingToolExecutor
📡wiretool_call / tool_result → UI
Implementation principle: The loop lives in query(), not in the model. Transports only call runChatTurn().

The LLM only selects tools; actual file access, command execution, and browser control are handled by ToolDefinition implementations and the executor.
