01 概述

CC 的「记忆」不是单一模块，而是多层、多生命周期的持久化上下文。按职责分成六大类：

#系统生命周期主要用途核心路径
1Instructions（CLAUDE.md）跨会话，人工指令/规范，始终注入utils/claudemd.ts
2Auto Memory（memdir）跨会话，自动+手动用户画像、反馈、项目事实、外部指针memdir/
3Team Memory跨会话，团队同步项目级共享（Auto 子目录）teamMemPaths.ts
4Agent Memory跨会话，按 agent子 Agent 专属记忆agentMemory.ts
5Session Memory单会话对话笔记，供 compactSessionMemory/
6Recall / Extract / Dream运行时流水线检索、抽取、整理见 §8

注意 · 两套 MemoryType

① 指令文件类型（utils/memory/types.ts）：User | Project | Local | Managed | AutoMem | TeamMem

② Auto Memory 内容类型（memdir/memoryTypes.ts）：user | feedback | project | reference

02 架构总览

会话启动 ├─ getMemoryFiles() → CLAUDE.md 层级 + MEMORY.md 入口 │ └─ getClaudeMds() → 注入 user context（指令） ├─ loadMemoryPrompt() → 系统提示：如何读写记忆 └─ Agent spawn └─ loadAgentMemoryPrompt() 每轮用户输入 └─ findRelevantMemories() → Sonnet 选 ≤5 条 topic 文件 └─ relevant_memories attachment 回合结束（stop hooks） ├─ extractMemories（主 agent 未直接写时） └─ Session Memory hook（阈值满足）→ Edit summary.md 后台 └─ autoDream（≥24h 且 ≥5 sessions）→ 蒸馏 MEMORY.md Compact └─ 优先用 Session Memory 代替整段 LLM 总结

03 Instructions Memory（CLAUDE.md）

人工编写的指令文件，会话一开始整文件注入，优先级高于模型默认行为。入口：/memory。

3.1 四级层级（低 → 高优先级）

类型路径作用域
ManagedmacOS /Library/Application Support/ClaudeCode/CLAUDE.md；Linux /etc/claude-code/CLAUDE.md全机策略
User~/.claude/CLAUDE.md + ~/.claude/rules/*.md用户全局
ProjectCLAUDE.md、.claude/CLAUDE.md、.claude/rules/*.md（CWD 向上）仓库
LocalCLAUDE.local.md（CWD 向上）本机私有

3.2 关键规则

  • 离 CWD 越近越晚加载 → 越高优先级
  • 嵌套 worktree 跳过主仓重复 Project 文件；Local 仍从主仓加载
  • 支持 @path include；仅文本扩展名；防循环
  • claudeMdExcludes 可排除 User/Project/Local
  • 单文件建议上限 40_000 字符

04 Auto Memory（memdir）

跨会话结构化主题记忆，只存无法从代码/git 推导的上下文。

4.1 目录结构

~/.claude/projects/<sanitized-git-root>/memory/
├── MEMORY.md              # 索引（常驻上下文）
├── user_*.md / feedback_*.md / project_*.md / reference_*.md
├── team/MEMORY.md         # Team Memory
└── logs/YYYY/MM/YYYY-MM-DD.md   # KAIROS 日日志

路径覆盖顺序：CLAUDE_COWORK_MEMORY_PATH_OVERRIDE → settings autoMemoryDirectory（禁 projectSettings）→ 默认 projects 路径。同一 git 的 worktree 共享目录。

4.2 四种内容类型

user

角色、目标、知识背景、协作偏好。帮助因人而异地解释与协作。

scope: 永远 private

feedback

纠正与确认的工作方式。含 Why / How to apply，避免只记失败变过度谨慎。

默认 private；项目公约 → team

project

进行中工作、动机、截止日期等非代码可推导事实。相对日期须存成绝对日期。

强烈偏向 team

reference

外部系统指针：Linear 项目、Slack 频道、Grafana 看板等。

通常 team

不要存

代码模式 / 架构 / 文件树 / git 历史 / 调试配方 / 已在 CLAUDE.md 的内容 / 仅当前对话有用的临时任务。

4.3 保存方式

  1. 写带 frontmatter 的主题 .md
  2. 在同目录 MEMORY.md 加一行索引（≤150 字符 hook）

MEMORY.md 硬限制：200 行 且 25KB。

4.4 与 Plan / Task

  • Plan：对齐实现方案
  • Task：当前对话步骤
  • Memory：跨会话仍有价值的信息

4.5 KAIROS 日日志

长会话模式下新记忆 append 到日日志；夜间 Dream 再蒸馏。与 Team Memory 互斥。

05 Team Memory

  • 路径：<autoMemPath>/team/
  • 需 Auto Memory 开启 + GB tengu_herring_clock
  • 写入经 realpath 校验，防 symlink / 路径穿越
  • 禁止在 team 记忆中存 API key 等敏感信息（提示词硬约束）

06 Agent Memory

Scope目录语义
user~/.claude/agent-memory/<agentType>/跨项目通用
project.claude/agent-memory/<agentType>/可进 VCS
local.claude/agent-memory-local/<agentType>/本机，不进 VCS

创建 agent 时 MemoryStep.tsx 选择 scope；spawn 时注入 loadAgentMemoryPrompt()。

项目可提交 snapshot（.claude/agent-memory-snapshots/），本地通过 .snapshot-synced.json 做 initialize / update / replace。

@agent-xxx 提及时，相关性检索只搜该 agent 目录。

07 Session Memory

单会话工作笔记，路径：

~/.claude/projects/<cwd>/<sessionId>/session-memory/summary.md

默认章节：Title / Current State / Task / Files / Workflow / Errors / Docs / Learnings / Key results / Worklog。

模板与 prompt 可自定义：~/.claude/session-memory/config/{template,prompt}.md。

触发阈值（默认）

  • Gate：tengu_session_memory；且 auto-compact 开启
  • 初始化：上下文 ≥ 10k tokens
  • 更新：再增长 ≥ 5k，且（工具调用 ≥ 3 或上轮无 tool call）
  • Forked agent 仅允许 Edit 该 summary 文件

与 Compact

sessionMemoryCompact.ts 可在压缩时用 summary 代替完整 LLM 总结，保留尾部消息窗口（约 10k–40k tokens）。

08 Recall / Extract / Dream

8.1 Relevant Memory Recall

  1. scanMemoryFiles：扫 frontmatter，排除 MEMORY.md，最多 200
  2. 侧路 Sonnet 按 query 选 ≤5 个文件
  3. 以 relevant_memories attachment 注入，附带新鲜度警告（>1 天）

tengu_moth_copse 开启时：MEMORY.md 不再常驻 system prompt，改走 attachment。

8.2 Extract Memories

  • Stop hook；仅主 agent；gate tengu_passport_quail
  • 主 agent 本轮已写 memory → 跳过（互斥）
  • 否则 fork，最多 5 turns；工具仅读 + memory 目录写

8.3 Auto Dream

  • autoDreamEnabled 或 GB tengu_onyx_plover
  • 默认：≥24h 且 ≥5 个有更新的 session
  • 蒸馏日日志 / 散文件 → topic + MEMORY.md
