# AI Coding Agent

从零构建你自己的编程助手

---

## 什么是 Coding Agent？

- 不只是代码补全 — 它能**自主完成任务**
- 读文件、写文件、运行命令、修复 Bug
- 一个循环：**思考 → 调用工具 → 观察结果 → 继续**

> "给 Agent 一个目标，它自己找路。"

---

## 核心架构

```
用户消息
   ↓
┌─────────────┐
│  Agent Loop  │ ← 大脑（LLM）
└──────┬──────┘
       ↓
┌─────────────┐
│    Tools     │ ← 手和脚
│  bash        │
│  read_file   │
│  write_file  │
│  edit_file   │
│  explore     │
└──────┬──────┘
       ↓
   工具结果 → 回到 Agent Loop
```

---

## 关键设计决策

**1. Tool 而不是 Prompt**
- 让 LLM 调用结构化的工具，而不是生成 bash 脚本
- 更安全、更可控、更容易调试

**2. EventBus 解耦**
- Agent 只发事件，不关心谁在听
- SSE？WebSocket？终端？都可以

**3. 子 Agent（Subagent）**
- 探索代码库时启动独立的 Agent
- 隔离上下文，不污染主对话
