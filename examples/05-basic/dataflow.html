8. Message Format (messages[])

The messages array is the core data structure. It's mutated in-place by the agent loop and persisted per session.

// User message (appended at start)
{ role: "user", content: "build me a REST API" }
// Assistant message (built from stream)
{ role: "assistant", content: [
  { type: "text", text: "Let me explore..." },
  { type: "tool-call", toolCallId: "call_abc", toolName: "bash", input: { command: "ls -la" } }
]}
// Tool result message (one per tool call)
{ role: "tool", content: [
  { type: "tool-result", toolCallId: "call_abc", toolName: "bash",
    output: { type: "text", value: "total 42\ndrwxr..." } }
]}
// After compaction — replaces old messages
{ role: "user", content: "[Previous work summary]\n\n## Task\n..." }
{ role: "assistant", content: "I have the context from the summary..." }
// ...followed by most recent 10 messages
