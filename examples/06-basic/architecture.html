⌨ bash
tools/bash.ts
Shell command execution via child_process.spawn. Timeout & output truncation.
📖 read_file

Read files with line numbers, offset/limit support.
✏ write_file

Subagents — subagents/
🏭 base.ts
subagents/base.ts
Factory: createSubagentDefinition(config). Scoped EventBus, subset of registry tools, isolated message history, calls runAgent recursively.
createSubagentDefinition()
🔍 explore
subagents/explore.ts
Read-only exploration subagent. Tools: read_file + bash only. Fixed system prompt for codebase analysis. Registered in router.ts at boot.
definition
Prompts — prompts/
📝 system.ts
prompts/system.ts
Dynamic system prompt. Reads tool list from defaultRegistry at call time.
Task-complexity-based guidance: Simple → just do it, Medium → read then edit, Complex → explore → plan → implement → verify, Empty dir → build immediately.
systemPrompt(cwd)

▸ Key Dependencies

router.ts (Composition Root)
  • imports EventBus, Middleware from core/
  • imports defaultRegistry from tools/
  • imports explore def from subagents/
  • imports session, sse-transport from server/
  • creates per-request context & wires everything
agent.ts (Core Loop)
  • imports streamText from AI SDK (ai)
  • imports defaultManager from provider-manager
  • imports summarizeIfNeeded from context
  • receives tools, eventBus, messages via args
system.ts (Prompts)
  • imports defaultRegistry from tools/
  • reads registry.list() for dynamic tool list
  • generates task-complexity-based guidance
External
  • ai — Vercel AI SDK (streamText, generateText, tool)
  • zod — Schema validation for tool params
  • typescript — Static type checking (tsc --noEmit)
  • tsx — TypeScript executor for Node.js
  • shared/provider.js — OpenAI-compatible client
  • LLM via copilot-proxy @ localhost:4141
